Google Sheets Real-time Sync

Hubungkan aplikasi ini ke Google Sheet Anda via Webhook Apps Script sederhana. Transaksi otomatis tersimpan di Google Drive.

Panduan Singkat Setup Google Sheets Apps Script

  1. Buat Google Sheets baru di Google Drive Anda (beri nama misal: "Wallet App Database").
  2. Buka menu Extensions > Apps Script.
  3. Hapus semua kode yang ada, lalu salin dan tempel kode berikut:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Buat header jika sheet masih kosong
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["ID", "Tanggal", "Tipe", "Kategori", "Jumlah", "Dompet", "Catatan", "Waktu Sync"]);
      sheet.getRange(1, 1, 1, 8).setFontWeight("bold").setBackground("#1e293b").setFontColor("#ffffff");
    }
    
    // Tambah baris transaksi baru
    sheet.appendRow([
      data.id || "",
      data.date || "",
      data.type || "",
      data.category || "",
      data.amount || 0,
      data.account || "",
      data.note || "",
      new Date().toISOString()
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({result: "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(error) {
    return ContentService.createTextOutput(JSON.stringify({result: "error", message: error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik Deploy > New deployment. Pilih type Web App.
  2. Atur Execute as: Me dan Who has access: Anyone. Klik Deploy.
  3. Salin Web App URL yang dihasilkan, lalu tempelkan di menu Pengaturan Google Sheets Sync!
